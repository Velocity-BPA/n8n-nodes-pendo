# Automate Your Product Analytics: Introducing the n8n-nodes-pendo Community Node

We're excited to announce that Velocity BPA has released a new community node for n8n that brings Pendo's powerful product analytics and user engagement platform directly into your automation workflows!

## The Challenge

Product teams using Pendo often find themselves manually exporting data, updating segments, or triggering guides based on events happening in other systems. Whether you're syncing user data from your CRM, triggering in-app guides based on support tickets, or pulling analytics into your data warehouse, these repetitive tasks eat up valuable time that could be spent on strategic work.

## Meet n8n-nodes-pendo

Our new Pendo node eliminates these manual processes by connecting Pendo seamlessly with the 400+ other apps and services in the n8n ecosystem. Now you can build powerful automations that leverage Pendo's capabilities without writing a single line of code.

## Key Features

The n8n-nodes-pendo community node provides comprehensive access to Pendo's core functionality:

**Analytics Operations**: Pull product usage data, feature adoption metrics, and user behavior insights directly into your workflows. Combine this data with information from other tools to create comprehensive reports or trigger actions based on usage patterns.

**Guide Management**: Programmatically create, update, and manage in-app guides. Trigger contextual guides based on events from other systems, such as sending a welcome guide when a new customer is added to your CRM.

**Visitor & Account Management**: Sync user and account data between Pendo and your other business systems. Keep customer information up-to-date across your entire tech stack automatically.

**Segment Operations**: Create and manage user segments dynamically based on data from multiple sources. Build sophisticated targeting rules that incorporate information beyond what's available in Pendo alone.

## Getting Started

Installing the Pendo node is simple. In your n8n instance, run:


npm install n8n-nodes-pendo


After installation, restart n8n and you'll find the Pendo node available in your node palette. Connect it using your Pendo API credentials and start building automations immediately.

For detailed documentation and examples, check out our GitHub repository: https://github.com/Velocity-BPA/n8n-nodes-pendo
